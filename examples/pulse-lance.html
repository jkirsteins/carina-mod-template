Pulse Lance ​

One research result and one beam weapon, released twice: version 1.1.0 renames the weapon's keys and carries a save migration.

Download .carinamod

1.6 KB, 5 files. Built from the repository when this site was built; it checks and imports the same as the folder.

How it works ​

In the game, an application of the Physics research field, Pulse Lance, is added, and a beam weapon of the same name is unlocked by it. This is version 1.1.0 of a mod whose version 1.0.0 called both records pulse_cannon. A game saved under 1.0.0 loads under 1.1.0, because the mod carries a migration that maps the old keys to the new ones.

The files responsible:

  • mod.json has version 1.1.0 and rulesVersion 2.
  • migrations/1-2.json renames the application and the weapon from carina_team.pulse_lance.pulse_cannon to carina_team.pulse_lance.pulse_lance.
  • records/applications/apps.json and records/weapons/beams.json hold the records under the new key.

How it works on a save:

  1. A save stores the mod's id, version, rulesVersion and hashes, and the ids of its records.
  2. Under 1.1.0 the running rulesVersion is 2 and the save's is 1, so the game looks for a migration for every step. migrations/1-2.json covers the step.
  3. Each saved id walks through the renames to the id of the new key, and the old id stays reserved.
  4. Without migrations/1-2.json the save is refused with missingModMigration.

Releasing an update describes the file format.

To adapt it:

  • Keep the old .carinamod to test with. See Testing an old save.
  • Add one rename for each key you change, and a removal for each record you delete.
