Modding Throne of Carina ​

Throne of Carina is a turn-based space strategy game that runs in the browser (play it on itch.io). This site is the modding guide, the generated reference, a set of example mods and a page that checks a mod.

Making a mod takes no programming. You edit JSON files, add pictures and sound, and run one command-line tool.

What a mod is ​

A mod is a folder, or a .carinamod file, which is that folder zipped. It holds data only: JSON records and rule changes, text, pictures and sound. No code runs from a mod. The game checks every mod when you import it and says what is wrong and where.

Where to start ​

  • Your first mod: make, check, pack and play a small mod.
  • Example mods: working mods to read, download and copy.
  • Check my mod: the game's importer in this page, without installing anything.

What a mod can add ​

  • Research fields, spliced into one of the eight research areas, with up to four applications each.
  • Beam weapons in full. Missiles, torpedoes, fighters and special weapons, with their combat-rules rows and an existing special kind.
  • Armour, shields and computers.
  • Ship specials. A new special adds no new behaviour.
  • Buildings, made from the closed list of effect kinds and the existing autobuild formulas.
  • Races and special race picks.
  • Text keys.
  • Pictures and sound for any base role, and pictures for new races and buildings.

What a mod can change ​

  • Any value of any base record, by patch rows. This includes the closed catalogs (Rules catalogs): hulls, drives, fuel cells, governments, combat rules and the computer players' tables. A value stays within its field's range, and a fixed table keeps its length.
  • Base records of the open catalogs can be removed.
  • The starting technology of each start level.
  • Technology that only a pick or a race can research.
  • Base text, except proper names. Base text lists the keys.

What needs a game update ​

  • New hulls, governments, drives and fuel cells. These catalogs are closed.
  • New effect kinds, special weapon kinds, weapon classes, weapon mods, autobuild formulas and trait levels.
  • A ninth research area, or a fifth application in a field.
  • New random events. The events catalog is closed.
  • Scenarios, campaigns, interface changes and scripts. The folders rules/, scenarios/, campaigns/, ui/ and scripts/ are refused with needs-newer-game.
  • Text in languages other than English. It is reported as text-locale-unused and not used.
  • A weapon cost that depends on the empire.
  • Quick-rebuild of a mod's buildings by Hard and Impossible computer players.

Limits lists every bound.

Multiplayer ​

In multiplayer every player needs the same rule mods. The game compares them by hash, not by name. A player who joins a game with mods they lack, or have in another version, sees which ones differ. The game never sends mods between players. GET FROM CATALOG installs the differing mods from the mod catalog when it lists them.

Every player holds the full rules of the game, so a mod cannot keep a rule secret. Pictures, sound and text may differ between players.
