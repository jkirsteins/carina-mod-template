JSON schemas ​

The schemas of the mod files, for your editor (completion and checks as you type).

The $schema value in each file is the format id, not a path. It must stay as it is:

File$schema
mod.jsoncarina-mod/1
records/<catalog>/*.jsoncarina-records/1
patches/*.jsoncarina-patch/1
assets/roles.jsoncarina-roles/1
migrations/*.jsoncarina-mod-migration/1

The template's .vscode/settings.json maps those ids to the files in schemas/. npx carina-modkit vscode writes schemas/ and .vscode/settings.json for every mod folder and prints wrote schemas/ and .vscode/settings.json (N mod folders).

To use the schemas without the template, add an entry for each file kind to your editor's settings and keep the format ids. An entry is the folder of the files plus the format id, mapped to a schema. One VS Code entry, for the manifest of mods/my-first-mod:

json
{
  "json.schemas": [
    {
      "url": "./mods/my-first-mod/carina-mod/1",
      "schema": { "$ref": "../../../schemas/mod.schema.json" }
    }
  ]
}

npx carina-modkit vscode writes these entries for every mod folder, so copy its output as the pattern.
