Sharing ​

This page covers how players get your mod: as a file, from the mod catalog or from a page you host.

A file ​

npx carina-modkit pack mods/<mod> writes the .carinamod. Give it to players with its sha256, which pack prints. A player imports it with MODS, then IMPORT.

Every mod you share follows content policy: your own work, or work whose licence allows it, and nothing taken from other games. Set a license in mod.json, and sources for outside material.

The mod catalog ​

The game's mod catalog is a curated list. Players find it in the game: MODS, then ONLINE CATALOG. INSTALL installs the mod, with the mods it needs.

To get listed, open a pull request or a Submit a mod issue in the catalog repository. Its SUBMITTING.md says how. You give:

  • your .carinamod or a link to your mod's page,
  • the sha256 that pack printed.

A pull request runs npx carina-modkit@^0.2.0 catalog add <your file> on the repository. Add --page <url> if you host the file yourself. The validate check must pass. The keeper reviews the mod, merges it and signs the catalog, and the game shows it within minutes.

The catalog stores packages of at most 20 MB.

Updates ​

A listed file never changes. Pack a new version and submit it the same way. Players see an update notice in the game. See Releasing an update.

External pages ​

Bigger mods, and mods you prefer to host yourself, for example on itch.io, are listed as external pages. The catalog lists the page and the file's sha256.

In the game, a player:

  1. Selects the mod in ONLINE CATALOG and presses OPEN PAGE, or GET IT ON the host's name.
  2. Gets the .carinamod there. The game says Hosted on <host>: get the .carinamod there, then use IMPORT on the INSTALLED tab.
  3. Imports it with IMPORT.

The import report says whether the file matches the listed sha256.

Mods that need other mods ​

A mod that lists a required dependency installs from ONLINE CATALOG together with it, when the catalog lists the dependency. If the catalog does not list it, INSTALL installs nothing and the detail pane says why. See Dependencies and compatibility.

A mod hosted on an external page cannot be installed as a dependency. The player installs it first.

Saves and rooms that need your mod ​

A save or a multiplayer room that uses a mod a player lacks lists the mods that differ. GET FROM CATALOG installs them, with the mods they need, when the catalog lists the exact packages the save or room uses. A mod that is only in a file or on an external page is installed by hand with IMPORT.
