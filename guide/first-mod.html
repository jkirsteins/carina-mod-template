Your first mod ​

This page makes a mod from the template, checks it, packs it and plays it in the game. It adds one weapon and changes one rule.

Set up ​

You need Node.js 22 or newer. An editor that reads JSON Schemas (VS Code, for example) helps.

  1. On the template repository, press Use this template.
  2. Run git clone https://github.com/<you>/<repository>.git.
  3. Run cd <repository>.

Every command below runs in that folder. pack writes its dist/ folder there.

The commands are written npx carina-modkit <command>. npx fetches the tool from npm the first time. To skip its question, write npx --yes carina-modkit <command>.

Create the mod ​

The id is yours for good: yourname.slug, lowercase letters, digits and hyphens.

sh
npx carina-modkit init mods/my-first-mod --id yourname.my-first-mod --title "My first mod" --author "Your name"

init writes mods/my-first-mod/mod.json and an empty patches/balance.json, and adds the folder to the VS Code settings. It makes no other folders, so you create records/weapons/ and i18n/en/ with the files below.

Add a weapon ​

Records you add go in records/<catalog>/. Their keys start with your id, with - read as _.

Create mods/my-first-mod/records/weapons/beams.json:

json
{
  "$schema": "carina-records/1",
  "catalog": "weapons",
  "records": [
    {
      "key": "yourname.my_first_mod.arc_lance",
      "application": "laser_cannon",
      "class": "beam",
      "ammo": null,
      "space": 12,
      "cost": 9,
      "damage": [4, 10],
      "strategicDamage": [4, 10],
      "mods": ["hv", "pd", "ap", "af"],
      "inherentBits": 0,
      "monster": false,
      "nameKey": "wpn.yourname.my_first_mod.arc_lance.name"
    }
  ]
}

application names the research result that unlocks the weapon. Here it is the one that unlocks the laser cannon. References to other records are always keys, never numbers. Every field is listed on the weapons page.

The weapon needs a name. Text goes in i18n/en/. The plural and the short note appear on the ship design screens, and about 35 characters of the note fit. They use the same key with .plural and .note in place of .name.

Create mods/my-first-mod/i18n/en/text.json:

json
{
  "wpn.yourname.my_first_mod.arc_lance.name": "Arc Lance",
  "wpn.yourname.my_first_mod.arc_lance.plural": "Arc Lances",
  "wpn.yourname.my_first_mod.arc_lance.note": "A crackling short-range beam."
}

Change a rule ​

A patch row changes a value that already exists. This one makes battles longer. expect makes the row fail if the game no longer has the value you built on.

Replace mods/my-first-mod/patches/balance.json (written by init) with:

json
{
  "$schema": "carina-patch/1",
  "patches": [
    {
      "op": "set",
      "catalog": "combat-rules",
      "key": "standard",
      "path": "roundLimit",
      "value": 60,
      "expect": { "roundLimit": 50 }
    }
  ]
}

Rows and their operations are described on Rules changes.

Check, pack and run ​

check runs the game's own checks and prints what the game would say on import.

sh
npx carina-modkit check mods/my-first-mod

run plays 50 turns with computer players under your rules and reports whether they used what you added. It takes a few seconds.

sh
npx carina-modkit run mods/my-first-mod --turns 50
text

  weapons yourname.my_first_mod.arc_lance: 29 designs carry it

If check prints an issue instead, see Troubleshooting.

Play it in the game ​

  1. Open MODS on the main menu.
  2. Press IMPORT and pick dist/yourname.my-first-mod-0.1.0.carinamod. In a desktop browser you can instead drop the file, or the mod folder, on the screen.
  3. Select the mod in the list. The details box shows Contains: rules, text, Rules mod: switch it on per game in New Game RULES., Adds: 1 weapons, Changes: 1 combat-rules and Works with the base rules.
  4. Start New Game, press the RULES row, switch My first mod on and press ACCEPT.
  5. Start the game.

Where the changes show ​

  • The weapon. The Arc Lance is unlocked by the Laser Cannon application of the Physics research field. From the Average start up, an empire knows the Laser Cannon on turn 1, so the Arc Lance is available in ship design from the start. The Pre-Warp start grants only one starting field, which is not Physics, so there the Arc Lance appears after you research Physics and choose Laser Cannon.
  • The round limit. No screen shows it. A battle that no side wins ends after 60 rounds instead of 50, and the attacker retreats. The Changes: line lists the catalog that was patched.

To edit and test without packing each time, use dev mode.
