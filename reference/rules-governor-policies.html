governor-policies ​

Patch rows on this catalog use "catalog": "governor-policies" and a key from the records below. The catalog is closed: a mod changes values with patch rows (see Patch operations) and cannot add records.

Records ​

development, research, military

Copy this row ​

A row that changes nothing: value and expect both hold the base value. Change value to the number you want.

json
{
  "op": "set",
  "catalog": "governor-policies",
  "key": "development",
  "path": "newColony.jobs.foodReserve",
  "value": 0,
  "expect": {"newColony.jobs.foodReserve":0}
}

append, insertAfter and removeValue rows apply to the list fields: defence, fallback, food, newColony.priorities, stages, stages.growing.priorities, stages.mature.priorities.

Keyed arrays: the path segment after the array names an element by its key field, then the element's field (stages.<key>.<field>). Rows on an element never conflict with rows on another element; a row on the whole array conflicts with both.

  • stages by key (any element key): jobs, jobs.foodReserve, jobs.minWorkersPct, jobs.scientistPct, maxFillPct, maxUnits, priorities
