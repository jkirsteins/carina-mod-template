audience-rules ​

Patch rows on this catalog use "catalog": "audience-rules" and a key from the records below. The catalog is closed: a mod changes values with patch rows (see Patch operations) and cannot add records.

Records ​

classic

Copy this row ​

A row that changes nothing: value and expect both hold the base value. Change value to the number you want.

json
{
  "op": "set",
  "catalog": "audience-rules",
  "key": "classic",
  "path": "acceptance.allianceMinRel",
  "value": 50,
  "expect": {"acceptance.allianceMinRel":50}
}
