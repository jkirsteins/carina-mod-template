diplomacy-rules ​

Patch rows on this catalog use "catalog": "diplomacy-rules" and a key from the records below. The catalog is closed: a mod changes values with patch rows (see Patch operations) and cannot add records.

Records ​

classic

Copy this row ​

A row that changes nothing: value and expect both hold the base value. Change value to the number you want.

json
{
  "op": "set",
  "catalog": "diplomacy-rules",
  "key": "classic",
  "path": "blockadeDie",
  "value": 5,
  "expect": {"blockadeDie":5}
}

append, insertAfter and removeValue rows apply to the list fields: levels, personalities, tribute.levels, war.totalWarDifficulties.

Keyed arrays: the path segment after the array names an element by its key field, then the element's field (personalities.<key>.<field>). Rows on an element never conflict with rows on another element; a row on the whole array conflicts with both.

  • personalities by key (any element key): breakPeacePct, breakWarPct, demandPct, diplomacyMod, gainScale, gainScale.den, gainScale.num, initialMood, lossScale, lossScale.den, lossScale.num, maxThreats, peaceUnit, sneakMod, threatInc
