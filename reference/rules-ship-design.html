ship-design ​

Patch rows on this catalog use "catalog": "ship-design" and a key from the records below. The catalog is closed: a mod changes values with patch rows (see Patch operations) and cannot add records.

Records ​

classic

Copy this row ​

A row that changes nothing: value and expect both hold the base value. Change value to the number you want.

json
{
  "op": "set",
  "catalog": "ship-design",
  "key": "classic",
  "path": "arcs.all.pct",
  "value": 50,
  "expect": {"arcs.all.pct":50}
}

Keyed arrays: the path segment after the array names an element by its key field, then the element's field (arcs.<key>.<field>). Rows on an element never conflict with rows on another element; a row on the whole array conflicts with both.

  • arcs by key (any element key): pct
  • auto.themes by key (any element key): weight
