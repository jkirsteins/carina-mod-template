start-state ​

Patch rows on this catalog use "catalog": "start-state" and a key from the records below. The catalog is closed: a mod changes values with patch rows (see Patch operations) and cannot add records.

Records ​

classic

Copy this row ​

A row that changes nothing: value and expect both hold the base value. Change value to the number you want.

json
{
  "op": "set",
  "catalog": "start-state",
  "key": "classic",
  "path": "levels.average.treasuryBase",
  "value": 50,
  "expect": {"levels.average.treasuryBase":50}
}
