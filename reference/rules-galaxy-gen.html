galaxy-gen ​

Patch rows on this catalog use "catalog": "galaxy-gen" and a key from the records below. The catalog is closed: a mod changes values with patch rows (see Patch operations) and cannot add records.

classic

Copy this row ​

A row that changes nothing: value and expect both hold the base value. Change value to the number you want.

{
  "op": "set",
  "catalog": "galaxy-gen",
  "key": "classic",

  "value": 45,
  "expect": {"blackHoles.blockRadius":45}
