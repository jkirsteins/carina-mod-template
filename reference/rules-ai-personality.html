ai-personality ​

Patch rows on this catalog use "catalog": "ai-personality" and a key from the records below. The catalog is closed: a mod changes values with patch rows (see Patch operations) and cannot add records.

Records ​

classic

Copy this row ​

A row that changes nothing: value and expect both hold the base value. Change value to the number you want.

json
{
  "op": "set",
  "catalog": "ai-personality",
  "key": "classic",
  "path": "cheatRules.freeFreighters.amount",
  "value": 5,
  "expect": {"cheatRules.freeFreighters.amount":5}
}
