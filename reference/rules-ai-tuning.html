ai-tuning ​

Patch rows on this catalog use "catalog": "ai-tuning" and a key from the records below. The catalog is closed: a mod changes values with patch rows (see Patch operations) and cannot add records.

Records ​

classic

Copy this row ​

A row that changes nothing: value and expect both hold the base value. Change value to the number you want.

json
{
  "op": "set",
  "catalog": "ai-tuning",
  "key": "classic",
  "path": "autobuild.keepWeight",
  "value": 55,
  "expect": {"autobuild.keepWeight":55}
}
