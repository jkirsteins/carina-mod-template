leader-rules ​

Patch rows on this catalog use "catalog": "leader-rules" and a key from the records below. The catalog is closed: a mod changes values with patch rows (see Patch operations) and cannot add records.

Records ​

classic

Copy this row ​

A row that changes nothing: value and expect both hold the base value. Change value to the number you want.

json
{
  "op": "set",
  "catalog": "leader-rules",
  "key": "classic",
  "path": "advancedStart.normal.count",
  "value": 2,
  "expect": {"advancedStart.normal.count":2}
}
