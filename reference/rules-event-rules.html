event-rules ​

Patch rows on this catalog use "catalog": "event-rules" and a key from the records below. The catalog is closed: a mod changes values with patch rows (see Patch operations) and cannot add records.

Records ​

classic

Copy this row ​

A row that changes nothing: value and expect both hold the base value. Change value to the number you want.

json
{
  "op": "set",
  "catalog": "event-rules",
  "key": "classic",
  "path": "allEventsDelay",
  "value": 50,
  "expect": {"allEventsDelay":50}
}
