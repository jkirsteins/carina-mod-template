movement ​

Patch rows on this catalog use "catalog": "movement" and a key from the records below. The catalog is closed: a mod changes values with patch rows (see Patch operations) and cannot add records.

Records ​

classic

Copy this row ​

A row that changes nothing: value and expect both hold the base value. Change value to the number you want.

json
{
  "op": "set",
  "catalog": "movement",
  "key": "classic",
  "path": "contact.add",
  "value": 1,
  "expect": {"contact.add":1}
}
