colony-economy ​

Patch rows on this catalog use "catalog": "colony-economy" and a key from the records below. The catalog is closed: a mod changes values with patch rows (see Patch operations) and cannot add records.

Records ​

classic

Copy this row ​

A row that changes nothing: value and expect both hold the base value. Change value to the number you want.

json
{
  "op": "set",
  "catalog": "colony-economy",
  "key": "classic",
  "path": "blockadePenaltyPct",
  "value": 50,
  "expect": {"blockadePenaltyPct":50}
}

append, insertAfter and removeValue rows apply to the list fields: sources.

Keyed arrays: the path segment after the array names an element by its key field, then the element's field (sources.<key>.<field>). Rows on an element never conflict with rows on another element; a row on the whole array conflicts with both.

  • sources by key (any element key): catalog, effects
