Check my mod ​

This page checks one mod at a time against the built-in rules. That is the same as npx carina-modkit check on a folder with no other mods next to it. For a mod that needs other mods, run the command line tool next to their folders, or with --with <folder>.

Drop your mod folder or a .carinamod file here to see what the game would say about it. The page runs the game's own strict importer and compiles the mod against the built-in rules.
